# 📚 LibSorter

> [!WARNING]
> ⚠️ **Проект находится в активной разработке!** (Версия 0.1.0)
> Это мой собственный проект приложения для сортировки библиотечного фонда. 
> Ранее он был написан на Python, а сейчас полностью переписывается на современный C++. 
> Старая версия будет выложена отдельно. Функционал может изменяться.

---

## Описание

Клиент-серверное приложение для каталогизации, поиска и сортировки библиотечного фонда. 
Архитектура разделена на ядро (модели, хранение, нечеткий поиск), серверную часть (WebSocket, аутентификация, роли) и клиентскую часть (графический интерфейс на Qt6/QML).

---

## 🛠 Стек технологий

- **Язык**: C++20
- **Сборка**: CMake (≥ 3.21)
- **Клиент**: Qt 6 (Core, Gui, Quick, Qml, Network, WebSockets)
- **Сервер**: Boost.Asio / Boost.Beast, OpenSSL
- **Данные**: `nlohmann/json` (сериализация и JSON-хранилище)
- **Тестирование**: `doctest`
